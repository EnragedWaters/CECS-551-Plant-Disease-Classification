# Start the demo here

Choose the file for your computer:

| Computer | File to open |
| --- | --- |
| Windows | **Windows - Run Demo.cmd** — double-click. WSL is optional. |
| macOS | **macOS - Run Demo.command** — double-click. |
| Linux / WSL | **Linux or WSL - Run Demo.sh** — run it, or use `bash "Linux or WSL - Run Demo.sh"` from this folder. |

Keep the terminal open while presenting. The browser opens automatically.
Choose a photograph and click **Run & show all stages** to see the full summary.
The **Compare 22 images per dataset** tab runs the sample comparison.
Press **Ctrl+C** in the terminal when finished.

First time on this computer? The Python environment, datasets and saved models
must be prepared. [Setup, troubleshooting and the offline backup](../docs/presentation/demo-guide.md)
explain what is needed. The launchers do not install or download anything.
